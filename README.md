# Leilões TDSat

## Sobre o projeto
Aplicação Java para apoiar rotinas de uma casa de leilões, incluindo cadastro de itens/lotes, registro de lances e arremates, e consultas administrativas.

## Tecnologias utilizadas
- Java (JDK)
- MySQL (SGBD)
- Git e GitHub

## Como executar (sugestão)
1. Importar o projeto na sua IDE (NetBeans/IntelliJ/Eclipse).
2. Configurar as variáveis de conexão com o banco (host, porta, usuário, senha).
3. Garantir que o banco MySQL esteja com o schema importado (arquivo fornecido pela disciplina).
4. Executar a aplicação.
